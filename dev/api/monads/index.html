Uncertainty monads and algebras

CategoricalDecisionAnalysis.AlphaMaxminMap — Type
AlphaMaxminMap(α)

The α-maxmin criterion on a credal set of distributions on the reals, α · lower + (1 − α) · upper expectation, α in [0, 1] the weight on the lower one (the convention of DecisionAnalysis's AlphaMaxmin). A structure map of the CredalMonad that is not an algebra unless α is 0 or 1.

CategoricalDecisionAnalysis.CVaRMap — Type
CVaRMap(α)

Conditional value at risk at level α in (0, 1] of a distribution on the reals: the mean of the worst α share of the probability mass (the convention of DecisionAnalysis's CVaR: a tail mean of a utility, so higher is better). A structure map of the DistributionMonad that is not an algebra for α < 1: the CVaR of a mixture is not the CVaR of the components' CVaRs, which is why it cannot be optimised stage by stage.

source
CategoricalDecisionAnalysis.CredalHull — Type
CredalHull(generators::AbstractVector{<:FiniteDistribution})

A finitely generated credal set: the convex hull of the listed distributions, a value of the CredalMonad. Repeated generators are merged. A generator need not be an extreme point; prune_generators removes those that are not.

== compares the lists of generators as sets, which is sufficient but not necessary for two hulls to be the same set. same_hull decides equality of the hulls themselves (by linear programme), and is what the monad laws hold up to.

CategoricalDecisionAnalysis.CredalMonad — Type
CredalMonad()

Finitely generated credal sets: a value is a CredalHull, the convex hull of finitely many finite distributions. Its algebras on the reals are the lower and the upper expectation (LowerExpectationAlgebra, UpperExpectationAlgebra).

Sequential composition only. Chaining with monad_bind (and so kleisli_compose) is well defined and sound: the composite set contains every distribution that the two steps can produce. It is also loose: the second step may choose a different member of its set for every outcome of the first, so a constraint that ties the steps together ("the same unknown rate at both steps") is forgotten and the composite set is larger than the truth. The monad is not commutative (the two orders of pairing two credal values give different sets), so its Kleisli category has no tensor product and this package offers no string diagrams for credal kernels (Liell-Cock and Staton 2025; graded credal kernels are the known repair and are not implemented).

ExpectationAlgebra()

CategoricalDecisionAnalysis.FiniteDistribution — Type
FiniteDistribution(outcomes, probabilities; atol)

A probability distribution with finite support: a value of the DistributionMonad. outcomes may be of any type and may repeat; equal outcomes are merged and outcomes of probability zero are dropped, so the stored outcomes are the support, in order of first appearance, and probabilities are positive and sum to one. The check is exact for integer and rational probabilities (atol = 0) and to atol = 1e-9 in floating point. Probabilities that are negative or do not sum to one throw InvalidBeliefError (DecisionAnalysis).

Two distributions are equal when they give every outcome the same probability, whatever the order they were written in.

julia> d = FiniteDistribution([:wet, :dry, :wet], [1 // 4, 1 // 2, 1 // 4])
FiniteDistribution(wet => 1//2, dry => 1//2)

julia> ExpectationAlgebra()(FiniteDistribution([10, 20], [1 // 4, 3 // 4]))
35//2

CategoricalDecisionAnalysis.FiniteSubset — Type
FiniteSubset(elements)

A non-empty finite set: a value of the PowersetMonad. Repeated elements are merged; the order of first appearance is kept for printing and is not part of the value (two subsets with the same elements are equal). An empty collection throws ArgumentError.

julia> FiniteSubset([:low, :high, :low])

julia> InfimumAlgebra()(FiniteSubset([30, 10, 20]))

CategoricalDecisionAnalysis.KleisliMap — Type
KleisliMap(monad, dom, codom, images)

A kernel in the uncertainty monad T: a map from the finite set dom to uncertain values over the finite set codom, stored as one value of T(codom) per element of dom (images[i] for dom[i]). For the DistributionMonad it is a stochastic kernel, for the IdentityMonad a function, for the PowersetMonad a total multivalued map, for the CredalMonad a credal kernel. Call it on an element of dom to get the image.

Build one from a column-stochastic matrix or a FiniteKernel with kleisli_map; compose with kleisli_compose; pull a utility back along it with value_pullback.

source
CategoricalDecisionAnalysis.LaplaceMap — Type
LaplaceMap()

The unweighted mean of the distinct values in a non-empty finite set of reals. A structure map of the PowersetMonad that is not an algebra: the mean of means is not the mean of the union.

It is not the Laplace rule of a decision table. A set has no multiplicities, so when an action pays the same in two states the set of its payoffs has one element where the table has two columns, and the two means differ. The Laplace criterion (DecisionAnalysis's Laplace) is the expectation under the uniform distribution on the states: it lives in the DistributionMonad, reached from the set of states by a map that is not a monad morphism, and rule_selection exhibits it that way. LaplaceMap is what Laplace() means as a criterion for a SequentialProblem whose chance stages are sets.

CategoricalDecisionAnalysis.LowerExpectationAlgebra — Type
LowerExpectationAlgebra()

The lower expectation over a credal set, α(c) = min_{p ∈ c} Σ_x p(x) x, attained at a generator: an algebra of the CredalMonad, behind Γ-maximin.

CategoricalDecisionAnalysis.MonadMorphism — Type
MonadMorphism(source, target)

A monad morphism τ : S ⇒ T between two uncertainty monads, applied to a value by calling it: τ(m). Build one with monad_morphism. The morphisms offered:

fromtowhat it does
identityanythe unit: a certain value as a point mass, a singleton, ...
distributionscredal setsthe set containing only that distribution
non-empty setscredal setsevery distribution on the set (the hull of its point masses)
distributionsnon-empty setsthe support

and the identity of each monad. They satisfy τ ∘ η = η and τ ∘ μ = μ ∘ τ ∘ S τ (tested on random inputs; for a credal target up to same_hull). There is none from credal sets to distributions or from sets to distributions: a set of possibilities does not determine probabilities.

The support is lax for the algebras. As a map of monads the support commutes with units and chaining (the support of a mixture is the union of the supports). It does not carry the expectation to the worst case with equality: the worst case over the support is a lower bound on the expectation, min over the support ≤ expectation ≤ max over the support (Lean pullbackMin_le_pullbackD). Replacing an expectation box by a worst-case box is a bound, not a rewrite.

Two routes from distributions to credal sets differ. The direct morphism sends p to {p}. Going through the support sends it to every distribution on the support of p, a much larger set. monad_morphism(DistributionMonad(), CredalMonad()) is the direct one.

CategoricalDecisionAnalysis.PowersetMonad — Type
PowersetMonad()

Non-empty finite sets (written P⁺): a value is a FiniteSubset, the outcomes that are possible, with no probabilities attached. Its Kleisli maps are total multivalued maps. Its algebras on the reals are the minimum (InfimumAlgebra, the worst case) and the maximum (SupremumAlgebra, the best case).

CategoricalDecisionAnalysis.RewardMonad — Type
RewardMonad()

Distributions over a reward and an outcome, R X = D(ℝ × X): a value is a FiniteDistribution over pairs (r, x). Chaining adds the rewards. Its algebra on the reals is the expected total reward, TotalRewardAlgebra, α(m) = Σ m(r, v) (r + v).

This is the monad behind RewardKernel of CategoricalInfluenceDiagrams: a Kleisli map X → R Y determines the reward kernel (K, W) with K(y | x) = Σ_r f(x)(r, y) and W[y, x] = Σ_r r f(x)(r, y) (reward_kernel), Kleisli composition maps to the expectation-semiring composition (K₁K₂, W₁K₂ + K₁W₂), and value pullback along f is the continuation value of that reward kernel. Of the three semantics that Abadi and Plotkin (2020) give for choice with probability and reward, this is the one in which only the expected reward is carried: (K, W) forgets how reward and outcome are correlated beyond the mean of the reward given the outcome, which is all that an expected-utility evaluation needs and not enough for a risk-sensitive one.

CategoricalDecisionAnalysis.StructureMap — Type
StructureMap

Supertype of the maps α : T ℝ → ℝ that turn an uncertain real number into one number, for an UncertaintyMonad T. A structure map is called on a value of its monad: α(m). monad_of gives the monad.

Some are Eilenberg-Moore algebras (is_algebra): they satisfy α(η x) = x and α(μ M) = α(T α M), which says that summarising in two stages is the same as summarising at once. These are IdentityAlgebra, ExpectationAlgebra, InfimumAlgebra, SupremumAlgebra, LowerExpectationAlgebra, UpperExpectationAlgebra, TotalRewardAlgebra and TransportedAlgebra. The others (HurwiczMap, LaplaceMap, CVaRMap, QuantileMap, AlphaMaxminMap) are aggregators in common use that fail the second law; algebra_multiplication_defect exhibits the failure. The distinction decides which rules can be solved stage by stage (admits_backward_induction) and for which value pullback is functorial (value_pullback).

source
CategoricalDecisionAnalysis.SupremumAlgebra — Type
SupremumAlgebra()

The maximum of a non-empty finite set of reals: the other algebra of the PowersetMonad on the reals, behind the best case (maximax) and, applied to regrets, behind minimax regret.

CategoricalDecisionAnalysis.TotalRewardAlgebra — Type
TotalRewardAlgebra()

The algebra of the RewardMonad on the reals: the expected total reward α(m) = Σ m(r, v) (r + v), the reward collected so far plus the value of the outcome.

source
CategoricalDecisionAnalysis.TransportedAlgebra — Type
TransportedAlgebra(base, φ, φ_inverse; translation_equivariant=false)

The algebra φ⁻¹ ∘ base ∘ T φ obtained by carrying the algebra base along an increasing bijection φ of the reals. With base the expectation and φ a utility function this is the certainty equivalent, u⁻¹(E u(X)): it is again an Eilenberg-Moore algebra, and monotone, so it admits backward induction on terminal payoffs. It commutes with adding a constant only for special φ (the exponential family); say so with translation_equivariant = true (see is_translation_equivariant). The caller is responsible for φ_inverse being the inverse of φ and for φ being increasing.

source
CategoricalDecisionAnalysis.UncertaintyMonad — Type
UncertaintyMonad

Supertype of the uncertainty monads on finite sets: IdentityMonad (no uncertainty), DistributionMonad (finite probability distributions), PowersetMonad (non-empty finite sets of possibilities, no probabilities), CredalMonad (finitely generated convex sets of distributions) and RewardMonad (distributions over a reward and an outcome). Each has monad_unit, monad_bind, monad_map and monad_join, and its Eilenberg-Moore algebras on the reals are structure maps (StructureMap).

For someone who does not use the word: a monad here is a kind of uncertain value ("one outcome", "a distribution over outcomes", "a set of possible outcomes", "a set of candidate distributions") together with the rule for chaining two uncertain steps into one.

source

UpperExpectationAlgebra()

The upper expectation over a credal set, max_{p ∈ c} Σ_x p(x) x: an algebra of the CredalMonad.

CategoricalDecisionAnalysis.admits_backward_induction — Method
admits_backward_induction(α::StructureMap) -> Bool
admits_backward_induction(rule) -> Bool

Whether a sequential problem under this criterion can be solved from the last stage backwards with the guarantee that the result is a best policy: is_algebra(α) && is_monotone(α).

criterionadmits backward induction
expectation (MaxExpectedUtility)yes
worst case (Maximin), best case (Maximax)yes
lower and upper expectation (GammaMaximin)yes, for the sequential (rectangular) composite of the credal kernels
certainty equivalent (TransportedAlgebra)yes, on terminal payoffs
Hurwicz, Laplaceno: not an algebra
CVaR, quantileno: not an algebra
α-maxminno: not an algebra
minimax regretno: regret depends on the menu, and the menu of a subproblem is not the menu of the whole problem

For a rule of DecisionAnalysis the answer is that of its aggregator, and false for any rule with a regret transform. The two counterexamples are in the test suite and in the vignette on backward induction (theorem C7c of the Lean development).

CategoricalDecisionAnalysis.algebra_multiplication_defect — Method
algebra_multiplication_defect(α::StructureMap, mm)

α(μ mm) − α(T α mm) for an uncertain value of uncertain reals mm ∈ T T ℝ: zero when α satisfies the multiplication law of an Eilenberg-Moore algebra at mm. Summarise the flattened value, or summarise each inner value and then the results: an algebra gives the same number both ways.

julia> inner1 = FiniteDistribution([0, 10], [1 // 2, 1 // 2]);

julia> inner2 = FiniteDistribution([4], [1]);

julia> mm = FiniteDistribution([inner1, inner2], [1 // 2, 1 // 2]);

julia> algebra_multiplication_defect(ExpectationAlgebra(), mm)
0//1

julia> algebra_multiplication_defect(CVaRMap(1 // 2), mm)
2//1

CategoricalDecisionAnalysis.belief_value — Method
belief_value(belief, [monad]; states=nothing)

A DecisionAnalysis belief as a value of an uncertainty monad over its state labels: a Symbol, a FiniteDistribution, a FiniteSubset or a CredalHull. Without monad it is the belief's own (belief_monad). With another monad the belief is carried along the monad morphism when there is one (monad_morphism), with one deliberate exception that follows DecisionAnalysis: a FiniteBelief, SampleBelief or CredalSet read as a set of possibilities (PowersetMonad) is the set of all its states, including states of probability zero, because that is the set the state-wise rules of DecisionAnalysis (Maximin, Maximax, Hurwicz, Laplace, MinimaxRegret) range over. It is not the support morphism, and for a credal set no monad morphism to sets is offered at all. states gives the states of the payoff table for a PointBelief read as a distribution or a set. Anything else throws MonadMismatchError.

CategoricalDecisionAnalysis.is_algebra — Method
is_algebra(α::StructureMap) -> Bool

Whether α is an Eilenberg-Moore algebra of its monad: α(η x) = x and α(μ M) = α(T α M). This is a declared property of each type (the statements are theorems C2, C4 and C5 of the Lean development), and algebra_unit_defect and algebra_multiplication_defect check it numerically on given inputs.

source
CategoricalDecisionAnalysis.is_monotone — Method
is_monotone(α::StructureMap) -> Bool

Whether making every outcome at least as good never lowers the summary: α(T f m) ≤ α(T g m) whenever f ≤ g pointwise. Every structure map of this package is monotone (TransportedAlgebra under its stated assumption that φ is increasing); the function exists because monotonicity is one of the two conditions for backward induction and a user-defined map must declare it.

source
CategoricalDecisionAnalysis.is_translation_equivariant — Method
is_translation_equivariant(α::StructureMap) -> Bool

Whether adding a constant to every outcome adds it to the summary, α(T (c + ·) m) = c + α(m): "adding a stage reward is an algebra map" (the third condition of Brede and Botta 2021). It holds for every structure map of this package except a TransportedAlgebra (a certainty equivalent), where it holds only for special transports and must be declared.

The backward induction of this package works on the payoff of whole histories, so it does not need this property; a dynamic programme that adds rewards stage by stage does.

source
CategoricalDecisionAnalysis.kleisli_compose — Method
kleisli_compose(f::KleisliMap, g::KleisliMap, hs...) -> KleisliMap

Sequential composition in diagrammatic order (first f, then g): (f ; g)(x) = monad_bind(f(x), g). For distributions this is the product of the stochastic matrices, and agrees with compose_kernel of FiniteKernels. For credal kernels it is the sound, loose composite described at CredalMonad. The two maps must be of the same monad (MonadMismatchError) and the codomain of f must be the domain of g (ArgumentError).

CategoricalDecisionAnalysis.monad_bind — Method
monad_bind(monad, m, f)

Chain an uncertain value m with a step f that turns each outcome into an uncertain value of the same monad (Kleisli extension, m >>= f):

  • identity: f(m);
  • distributions: the mixture Σ_x m(x) f(x);
  • non-empty sets: the union of the f(x) for x in m;
  • credal sets: the hull of every mixture Σ_x p(x) q_x with p a generator of m and q_x a generator of f(x), chosen separately for each x (see CredalMonad for why this is sound but loose);
  • rewards: the mixture, with the reward of m added to the reward of f(x).

CategoricalDecisionAnalysis.restrict_algebra — Method
restrict_algebra(τ::MonadMorphism, α::StructureMap) -> RestrictedMap

The structure map α ∘ τ of the source monad of τ. Restricting an algebra along a monad morphism gives an algebra, and the standard ones restrict to each other: the lower expectation along distributions → credal sets is the expectation, and along sets → credal sets is the minimum. This is the sense in which a belief and an aggregator of different monads fit together when a morphism connects them.
